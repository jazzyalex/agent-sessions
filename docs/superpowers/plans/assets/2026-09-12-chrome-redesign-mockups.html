Build order

  1. Transcript toolbar to one row. Self-contained, biggest visible weight drop, touches no data and no other view.
  2. Main toolbar to five groups — pills, search, actions, view, menu. Moving a control into a menu is a relocation, not a rewrite.
  3. One warm neutral for all chrome plus the inspector surface. Needs a token pass, so it wants its own commit.
  4. Inspector row policy — hide Delegated when the provider cannot produce it, make Weekly quota's absence actionable. This one changes what is claimed about data, so it deserves the most review.

All four are presentation-only. If any of these get built, they belong in a separate worktree — another session is on the telemetry code right now.
