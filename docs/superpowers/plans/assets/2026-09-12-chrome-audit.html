Agent Sessions · chrome audit · 2026-09-11

The chrome is louder than the content

Five issues, one cause: every control that has ever been useful is on screen at all times, at equal weight. Eighteen icons in the main toolbar, a two-row transcript toolbar, and a view-mode dropdown sized like a primary action for a feature nobody opens twice. This audit ranks controls by how often a person running a dozen agent sessions a day actually touches them, then puts everything below "weekly" behind a menu.

Who this is for

Someone running 10–50 agent sessions a day across Codex and Claude. Not a first-time Mac user, not a casual reader.

What they come here to do

Find the session where something happened. Read what the agent did. Check what it cost and which model ran.

What they never do

Read raw JSON. Switch to Text view. Change the font size more than once, ever. Press Refresh — they expect it to be current.

01

Weekly quota and Delegated are dead rows

Delegated can never have a value in a Codex session — remove it there, don't leave an em dash. It is not a bug and not missing data: the Codex accumulator hard-codes every usage record as self-owned, so there is nothing to delegate. Only Claude marks records as delegated, and only when the session used subagents.

Codex: CodexTelemetryAccumulator.swift:159 writes ownership: .session as a literal. No other value is reachable.

Claude: ClaudeTelemetryAccumulator.swift:116 writes ownership: isSidechain ? .descendant : .session. A Claude session with no Task-tool subagents is also legitimately empty.

Weekly quota is different — it is real but conditional. It needs an account-window calibration; without one there is no honest number to show.

Two different absences deserve two different treatments, and the current panel gives them the same em dash:

CaseTreatment
Structurally impossible
Delegated, in any Codex session		Don't render the row. A permanent em dash teaches the reader to ignore the column.
Possible, absent here
Delegated in a Claude session with no subagents		Don't render it either. "This session delegated nothing" is the default; only the exception is worth a row.
Possible, blocked
Weekly quota with no calibration		Keep the row, keep the em dash — but make the tooltip a fix, not an explanation: "Open Quota Meter to calibrate." An absence the reader can act on is worth its line.

Net effect on the screenshot: the Codex session loses the Delegated row entirely and keeps Weekly quota with an actionable tooltip. Two dead lines become one live one. Rename it Delegated to subagents when it does appear — "Delegated" alone doesn't say to whom, which is exactly the confusion here.

02

Light mode: the inspector is the only white thing on screen

The panel paints controlBackgroundColor — pure white — while the transcript beside it is a warm paper tone. Dark mode looks integrated because every dark surface collapses toward the same near-black; light mode exposes that the app never picked one neutral. The fix is a three-step ramp with a consistent warm bias, not a new color for the inspector.

Level 0 · Chrometoolbars, session list, inspector
Level 1 · Papertranscript body — the only lifted surface
Level 2 · Cardmessage cards on paper

The rule that makes this hold: the transcript is the only thing that gets a lifted surface. Everything that frames it — session list, both toolbars, the inspector — sits on Level 0 and shares one warm neutral. The inspector is chrome, so it belongs at Level 0, not above the paper it annotates.

Both themes need the same treatment applied, not inverted: in dark mode Level 1 is slightly darker than the chrome, not lighter, because a raised light surface in a dark UI reads as a modal.

03

The Session info icon

info.circle is the weakest choice available — it means "about this app" everywhere else in macOS, and it sits one slot away from an identically-weighted sidebar toggle. The panel is not general information; it is what this session cost and what model ran. The icon should say meter, not help.

info.circle

Today. Reads as "about", collides with the standard Help affordance, and carries no hint of cost or usage.

gauge.with.needlePick

Reads instantly as consumption. Pairs conceptually with the Quota Meter without duplicating its grid icon, and nothing else in the toolbar is round-with-a-needle.

receipt

Most literal for "what this run cost". Risks implying a real invoice, which the panel explicitly is not — it is an API-equivalent estimate.

sidebar.trailing

The strict macOS idiom for an inspector — Xcode uses exactly this. Correct, but unusable here while a near-identical sidebar.right sits beside it.

Whichever wins, it must be the only right-side panel toggle at full weight. Two adjacent controls that both mean "show a panel on the right" is the actual complaint behind "need a nice one".

05

Transcript toolbar: two rows for one row of work

The Session ⌄ dropdown is the loudest control in the transcript and switches between Session, Text and JSON — a choice made once, by a debugging author, and never again. It is a filled, labelled menu button sitting where the primary action goes. Meanwhile the role filters, which are used constantly, are exiled to a second row with four sets of ▲▼ arrows attached.

ChangeWhy
View mode leaves the toolbarInto the ⋯ menu as "View as ▸ Session / Text / JSON", plus ⌘1 / ⌘2 / ⌘3. A choice made once a year does not deserve permanent primary placement.
"All" chip disappearsNo filter selected already means all. The chip only existed to undo the other four.
▲▼ arrows disappearJump-to-next-occurrence stays on ⌘G / ⇧⌘G and appears on the active chip on hover. Four permanent arrow pairs for one navigation action is eight controls doing one job.
Errors chip carries a countThe one filter with real signal. Errors 2 tells you whether to press it; a bare dot doesn't. Zero errors, no count, dimmed chip.
A− / A+, Copy, ExportInto the ⋯ menu. Font size is set once; ⌘+ / ⌘− already work. Copy and Export are both "get this out of the app" and read better as one menu section than two buttons.
ID keeps its placeThe one piece of identity a vibe coder genuinely copies. Losing the "ID" prefix saves width — ⧉ a277 is unambiguous next to a copy glyph.

If you only ship three things

  1. Collapse the transcript toolbar to one row and move view mode into the overflow menu. This is the single largest weight reduction on screen and touches no data.
  2. Empty the main toolbar down to source pills, search, three view toggles, and a menu. Nothing is removed from the app — it moves to where its frequency says it belongs.
  3. Pick one warm neutral for all chrome so light mode stops looking like two apps stitched together, and drop rows that can never have data.

Everything here is presentation. The one item that needs a decision beyond taste is the Delegated row, because hiding it is a claim about the data: it is correct for Codex today because the accumulator cannot produce delegated records, and that would have to be revisited if Codex ever reports subagent usage.
