A coding agent's session file is the only durable record of what it did to
your codebase: what was asked, what ran, what it cost, what broke. We parse
ten of these formats in production, and after four months of fingerprinting
them weekly we can say the field's standard of care is low. Formats drift
without notice, three of ten carry no version marker, and not one vendor
documents their schema.

Opinions about that are cheap, so we turned ours into a benchmark.
**[Session Bench]({{ '/bench/' | relative_url }})** scores the session
format of every harness we support on nineteen scored pass/fail gates
across five areas: signal density, completeness, stability, openness, and
tooling cost. No partial credit, no vibes; a gate is pass, fail, or
explicitly not run, and every verdict traces to a byte measurement, a
fixture in our repo, or an entry in the drift ledger. Scores are emitted by
an evaluator from a measurements manifest and an evidence checklist, both
public — to dispute a grade, dispute an input and re-run it. The bench page
is permanent, and grades will change when formats do. One caveat on scope,
stated plainly: v0.1 measures each harness's CLI session store; desktop and
IDE surfaces can differ and get their own rows in a future version.

## The v0.1 leaderboard

| # | Harness | Format | Gates cleared |
|---|---|---|---|
| 1 | **Pi** | flat parent-linked JSONL | **17** / 19 |
| 2† | **OpenClaw** | flat parent-linked JSONL | **16** / 18 |
| 3 | **Claude Code** | nested-envelope JSONL | **14** / 19 |
| 4† | **OpenCode** | SQLite rows | **13** / 18 |
| 5 | **Codex** | nested-envelope JSONL | **12** / 19 |
| 5 | **Kimi Code** | wire-op journal | **12** / 19 |
| 7 | **Copilot CLI** | event-sourced JSONL | **11** / 19 |
| 8† | **Hermes** | SQLite ledger + FTS | **10** / 18 |
| 9 | **Antigravity** | step-typed JSONL | **9** / 19 |
| 10 | **Cursor Agent** | flat JSONL + binary metadata DB | **8** / 19 |

† One measurement could not be taken (broken headless runtime, auth
failure, or no store-size figure comparable across formats), so that gate
is *not run* and drops out of the denominator, and the rank is provisional
within a stated best/worst range on the bench page. An authentication error
is not evidence about a format. Ranking is by fraction of scored gates
cleared; ties share a rank.

The signal gates come from a controlled probe: the identical one-line
prompt ("List the files in the current directory, then say hello in one
sentence."), attempted headless through every harness, with each resulting
session artifact measured byte for byte and each failed run recorded as
exactly that.

The full gate-by-gate matrix, with the evidence behind every cell, is on
[the bench page]({{ '/bench/' | relative_url }}). The short version of how
each grade was earned:

**Pi, 17/19.** The smallest harness in the set keeps the cleanest record:
per-event timestamps, per-message model, token counts, dollar cost, readable
thinking, first-class compaction events, and a 1.5 KB log for our
standardized one-line task. It drops points only for undocumented schema
(everyone does) and for leaving abandoned branches in the file for naive
readers to trip over.

**OpenClaw, 16/18.** The other small harness. Full usage accounting
including dollars, tool calls with outputs, stable schema all four months.
Its size probe is marked not-run rather than scored — the headless path
refused to authenticate, which is a fact about automation readiness, not
about the format — and the bench says so instead of guessing.

**Claude Code, 14/19.** Genuinely good bones — per-line version stamps,
model and usage on every assistant event, subagent trees, fifteen-plus
additive changes in four months without one breakage. It bleeds points on
what it writes: 40 KB for a one-line exchange (two-thirds of it attachment
records), a content-key share of 23.9% of corpus bytes, no dollar figure, and
about 97.5% of recent thinking blocks are cryptographic signature with the
text stripped. The reasoning is certified to have happened. You just can't
read it.

**OpenCode, 13/18.** The most honest database design: every text chunk an
addressable row, plaintext reasoning, dollar cost recorded, and its biggest
rows turn out to be actual work product (tool outputs, diff summaries), not
bookkeeping dumps. Its lean-session gate is not-run, stated plainly: the
probe wrote about 5 KB of logical rows, but a physical before-and-after
store measurement comparable to the JSONL harnesses (pages, indexes, WAL)
hasn't been taken yet, and we won't score a number we didn't measure. It
still pays for the architecture in bench terms: nothing to `tail -f`, and a
JSON-to-SQLite migration inside our observation window.

**Codex, 12/19.** The most complete replay format and one of the most
wasteful. Every turn is logged twice by design (a UI event plus the exact
wire item), reasoning is `encrypted_content` on your own disk, there are no
thread links, and its `world_state` context snapshots reach 41.6 KB per
line in real sessions. It is also the only format here whose log
occasionally answers the prompt: in our controlled run, the model read the
file listing out of its own session file's world snapshot instead of
running the tool.

**Copilot CLI, 11/19.** The best telemetry in the set (router scores, token
checkpoints, a full shutdown accounting event) wrapped in the worst fixed
cost: it writes its complete system prompt into every session, a 52 KB line
in a 67 KB log. It also moved its entire storage layout at v1.0, and its
session title lives in a sidecar YAML file.

**Kimi Code, 12/19.** The strangest format we track: a wire-operations
journal where retries (`attempt: "2/10"`), steering, and cancels are all in
the record — real forensic value. It is also 0.9% content by bytes,
snapshots a 70 KB tool catalog every session, splits user and model content
into two disjoint op families that a naive reader will half-miss, and is
the only format that declares a protocol version in the artifact itself.
We initially scored that marker as dishonest — the installed bundle ships a
1.5 constant while sessions say 1.4 — then traced the actual writer and
reversed ourselves: the binary carries two protocol generations side by
side, and the one that wrote our session stamps 1.4 truthfully. The bench
keeps the receipts either way.

**Hermes, 10/18.** The only format that can search itself — a trigram
full-text index inside the database — plus real dollar accounting. But
model attribution is session-level, there is nothing to tail, it migrated
storage backends inside the window, and querying the live database turned
up a 36 KB system prompt stored in nearly every session row (116 of 118) —
the same fixed-cost habit as Copilot, just hidden in a column instead of a
log line. Its size
probe is not-run: the headless one-shot mode has returned no output since
late June.

**Antigravity, 9/19.** Tidy 6.8 KB logs with per-event timestamps, and
then the completeness floor gives out: no model field anywhere (our parser
regexes model changes out of user-input text), no token counts, user
content wrapped in XML tags inside JSON strings, and the largest storage
migration we observed — markdown artifacts to JSONL, mid-window.

**Cursor Agent, 8/19.** Last place, and the leanest file in the bench, which
is the point: 1.9 KB per session because the transcript records no
timestamps, no model, no token counts, no cost, and no tool outputs. (Tool
*calls* appeared sometime since July — an undocumented change we caught by
re-measuring.) Session metadata lives in a separate database of protobuf
blobs and hex-encoded JSON, so the one format that looks the most readable
at first glance is the only one you cannot actually read your history out
of with standard tools.

## The gate that fails everyone

O3, documented schema: ten harnesses, ten fails. Every parser of these
files — ours included — is reverse-engineered, and every one of them breaks
a little when a vendor renames a field. There is an open GitHub issue
asking Copilot to formalize `events.jsonl` as a stable surface; it sits
unanswered. These files hold months of paid working history. The industry
position, in practice, is that they are none of your business.

The drift data says this is not hypothetical caution. In four months of
weekly checks, four of ten formats had a structural break: Copilot moved
flat files to per-session directories at v1.0, OpenCode and Hermes each
replaced JSON storage with SQLite, and Antigravity swapped markdown
artifacts for JSONL wholesale. Three of ten still carry no version marker
of any kind, so a parser learns about changes by failing.

## Using this to choose a harness

The composite score rewards all-rounders; most developers care about one
property more than the rest. From the gate data: if you want local cost
accounting in dollars, only Pi, OpenClaw, OpenCode, and Hermes write it. If
you want history you can grep and tail, the flat-JSONL harnesses (Pi,
OpenClaw) and the big nested-JSONL ones (Claude Code, Codex) all qualify;
the database camp does not. If you want to search your history without
installing anything, Hermes is alone. If you want reasoning you can still
read next quarter, that rules out Claude Code and Codex today. And if being
able to read your own record back matters at all, Cursor's binary metadata
store is the one to avoid. The
[bench page]({{ '/bench/' | relative_url }}) keeps a per-area breakdown for
exactly this kind of narrowing.

## What passing would look like

The bench encodes it: write append-only lines you can tail, keep
conversation above a quarter of the bytes, stamp model and usage on every
message, record cost in currency, keep a readable rationale in the record
(sealed chain-of-thought may be legitimate policy, but then store a
summary), declare a version honestly, don't move the store, and publish the
schema. No harness clears all nineteen scored gates today. Pi is two away.
The gates are not exotic; they describe a format that respects the person
whose disk it is written to.

Grades will move — that is the point of a standing bench. The
[monitoring ledger and methodology](https://github.com/jazzyalex/agent-sessions/tree/main/docs/agent-support)
and the [drift log](https://github.com/jazzyalex/agent-sessions/blob/main/docs/agent-json-tracking.md)
are public, re-runs happen with our weekly monitoring, and disputes are
welcome as issues. [Agent Sessions](https://github.com/jazzyalex/agent-sessions)
itself is a free, local-only macOS browser for all ten of these stores;
reading them every day is how the bench got built.
