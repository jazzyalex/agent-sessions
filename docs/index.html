Quota Meter

How fast each session burns your plan — and how much you have left. Quota Meter reads your Codex and Claude 5-hour and weekly limits alongside active-session burn, so one glance shows which sessions use your quota and when each limit resets. Keep it in view:

  • In the notch — weekly Codex and Claude levels sit beside the MacBook camera, or at the top center of a display without a notch. Hover to open the full meter with session burn; move away and it folds back.
  • Always-on widget — or keep it as a tiny desktop window with your Codex & Claude 5h / weekly runway on screen.
  • Session Runway — per-session burn bars show active Codex usage. Weekly local estimates include archived session history and show pace without a run-out time.
  • Priced per model — the $ lens rates each model in a session separately, so an Opus orchestrator driving Sonnet subagents is costed at what each actually runs at rather than blended into one number.
  • Run-out predictions — freshness-aware ETAs where the measured quota data supports them.
  • Quota Meter alerts — separate controls for predicted exhaustion vs. low-threshold warnings.

Session Info

What a supported agent session recorded, beside its transcript. Press ⇧⌘I and the panel starts with quick info for every source, then reads the session's own records when detailed telemetry is available:

  • Quick info for every source — provider, current model or configuration, and title when recorded.
  • Detailed telemetry where available — price at API rates, token mix, model history, request count, and activity.
  • Honest boundaries — unsupported cost, quota, token, and history fields stay unavailable instead of being inferred.

The price is an estimate, not your plan bill.
